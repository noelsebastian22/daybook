# MCP Server Implementation Plan

**Goal:** A remote MCP server that lets an approved user read and change their
own Daybook from Claude, with the app's rules, as themselves, under RLS.

**Architecture:** A pure domain module in `supabase/functions/_shared/domain/`
imported by both the Angular store and a new `mcp` Edge Function. Supabase's
OAuth 2.1 server issues user tokens; the app hosts the consent page; the
function serves Streamable HTTP, statelessly, through a user-scoped client.

**Tech Stack:** Angular 22 zoneless, NgRx SignalStore, Supabase Postgres + Auth
OAuth 2.1 server, Deno Edge Functions, `@modelcontextprotocol/sdk`, chrono-node,
Vitest via `@angular/build:unit-test`, `node *.test.mjs` for function cores.

**Spec:** [`docs/MCP-PLAN.md`](../MCP-PLAN.md). Decisions D1–D4 closed 6 Oct:
D1 as below, D2 no `created_via`, D3 every approved user, D4 the raw
`functions/v1/mcp` URL.

## Global Constraints

Everything in `AGENTS.md` and the access-gate plan's list, plus:

- **The function never sees `service_role`.** Every query runs on a client
  built from the caller's bearer token.
- **The domain module is pure.** No Angular, no Supabase client, no `Deno`,
  no reads of the device clock or zone except where a caller passes them in.
- **Relative imports inside `_shared/` carry `.ts`.** Deno requires it;
  Angular accepts it through `rewriteRelativeImportExtensions`.
- **Bare `chrono-node`** in shared code. The app resolves it from
  `node_modules`; each function maps it in its own `deno.json`.
- **Edge Functions deploy with the Supabase CLI** from a committed tree.
- **Never log task text or notes.**

## D1, closed by spike, 6 Oct

`supabase/functions/_shared/domain/`, imported from `src/app/core/*` by
relative path. Proven on a throwaway pair of files: `ng build` compiles it
once `tsconfig.json` has `"rewriteRelativeImportExtensions": true` (without
it, TS5097); `deno check`, `deno run` and `deno bundle` resolve it with a
function-level `deno.json` mapping `chrono-node` to `npm:chrono-node@2.10.1`;
`node` imports it directly. **Not proven: `supabase functions deploy`**, which
needs the CLI on Noel's machine. It uses the same Deno resolution, so the
risk is low; task 6 closes it.
